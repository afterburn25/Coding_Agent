# Changelog — Nexus Core

All releases use the canonical `VERSION` file as the single version source.
Derived artifacts (pyproject, installer defaults, .NET project, PyInstaller
backend resource, `.agent/project.json`) are regenerated by
`python scripts/sync_version.py` — run automatically by
`packaging/build_windows.ps1` and verified by `tests/test_version.py`.

## [0.7.0] — Unreleased

Platform-expansion release line: persistent autonomy + modular AI workstation.

### Added

- **Nexus Autonomy** (`localcodeagent/autonomy/`): durable missions under
  `data/autonomy/` (schema v1), dependency-aware task DAG with leases and
  resource locks, bounded event-driven supervisor, planner/evaluator,
  recovery playbooks, policy profiles + standing grants, persistent
  scheduler, trigger engine, standing goals, notification center, mission
  approvals, `stop autonomy`, restart-safe recovery, Missions UI
  (`/missions.html`), `/api/autonomy/*` endpoints, chat mission commands.
- **Canonical versioning**: top-level `VERSION` file +
  `localcodeagent/version.py` + `scripts/sync_version.py` driving
  pyproject, Inno Setup defaults, the .NET desktop project, the
  PyInstaller backend version resource, and `.agent/project.json`.

### Changed

- Server `VERSION` now derives from `localcodeagent/version.py` instead of
  a hardcoded string — UI, `/api/status`, diagnostics, and startup banner
  all report the canonical version.
- `packaging/build_windows.ps1` regenerates `backend_version.txt` and
  syncs all version artifacts before compiling.

### Migration notes

- None required. `data/autonomy/` is created on first boot; existing
  user data (Brain, Answer Memory, conversations, models, settings) is
  untouched.

### Tests

- `tests/test_autonomy.py`: 49 tests. Full suite: 698 passing
  (2 environment skips) at autonomy milestone.

### Known limitations

- Async subsystem jobs (image/model-install) are not yet DAG node kinds.
- Brain/Answer-Memory integration into mission planning/evaluation is
  shallow — lessons are recorded but not yet retrieved during planning.
