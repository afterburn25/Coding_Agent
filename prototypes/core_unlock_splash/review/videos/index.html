Nexus Core — splash sequence review

Four separate MP4s with sound. The videos demonstrate presentation; they do not report live application state. Read docs/SPLASH_SEQUENCES_DEVIN_HANDOFF.md in the repository for integration, or the export instructions.

1. Startup · 30 seconds

Original opening, followed by about 18 seconds of fully powered animation and sustained hum.

Save startup MP4

2. Error · 12 seconds

Starts fully powered, flashes red, then stops at USER INTERVENTION · REQUIRED with recovery options. Wait for Retry; do not automatically continue.

Save error MP4

3. Recovery · 27 seconds

Starts only after Retry is clicked. Red fades to cyan/blue and white during stability recovery; confirmed success ends with green online text.

Save recovery MP4

4. Recovery failed · 13 seconds

Play if the user-requested retry fails. This reference branches from recovery at 8.8 seconds, stays contained and returns to user intervention without another automatic attempt.

Save recovery-failed MP4
